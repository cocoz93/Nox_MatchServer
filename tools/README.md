## 2026-09-12 — 하네스 84개를 지웠다

지운 것 = 정품 클라를 **마우스·키보드 주입으로 몰던 도구 일체**와 그 판정기
(`two_genuine` · `walk_genuine` · `matrix_run` · `matrix_judge` · `di` · `cycle` ·
`nav` · `capwin` · `graduation` · `pick*` · `onox_*` · 실험 캡처 PNG 30장 67MB).
git 이력에 남아 있으니 필요하면 꺼낼 수 있다.

### 왜 지웠나 — 둘 다 **우리가 만든 문제**였다

**⑴ 판정이 안쪽에 있었다.** 하네스가 `판끝O(8틱)` · `✅ 유효 — 캡처 14장` 같은
**판정처럼 생긴 글자**를 내놓는데, 그 근거는 전부 **서버 안의 변수**(`roundOver_`)였다.
서버가 자기를 채점한 것이다. 09-12 에 「3직업 × 3모드 9/9 판끝」이라 적었으나
사람이 직접 켜 보니 화면에서는 되는 것이 없었다.
★ `캡처 14장` 이 가장 고약했다 — **찍힌 장수만 세고 아무도 안 열었는데** 화면까지
  확인한 것처럼 읽힌다.

**⑵ 조작을 사람 손 흉내로 했다.** 클라가 서버에 보내는 패킷은 정답지에 다 있다
(`opennox/src/legacy/server__network__sdecode.c` 가 클라→서버 디코더).
그런데 마우스를 주입해 몰다 보니 **게임과 무관한 문제**가 줄줄이 생겼다 —
인게임 커서 배율 · 화면각↔월드각 표 · 커서를 25단위씩 나눠 밀기 ·
프레임당 입력 제한 우회. 전부 **접근을 바꾸면 사라지는 것**들이다.
★ 옛 README 는 배율을 `3.06`, 나중 도구는 `1.22` 라 적고 있었다. 같은 값을 두 번
  재서 서로 어긋난 채 둘 다 남아 있었다.

### 그래서 다음 도구가 지켜야 할 것

    ① 조작은 **패킷으로** — 정답지(Go·C)에서 읽어 만든다. 배율 같은 건 재지 않는다
    ② 판정은 **바깥에서** — 정품과 나란히 놓고 다른 것만 센다
    ③ **화면을 본 기록이 없으면 「판정」이라는 말을 쓰지 않는다**
       도구는 「서버 상태」까지만 말한다. 화면은 사람이 보거나 그림을 대조한다

대전제는 `Docs/SOURCE_POLICY.md` 에 있다 — ① Go 읽기 → ② C++ 구현 →
③ C 대조 → **④ 정품 클라 화면으로 확정**. ④ 를 뺀 것이 이번 일의 뿌리다.
