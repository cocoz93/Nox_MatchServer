# tools — 실측·자동화 도구

정품 녹스 클라이언트를 상대로 실측을 뜨고, 게임 화면을 자동으로 몰기 위한 PowerShell 도구들.
전부 **Windows PowerShell 5.1** 기준이고, **한글이 들어 있어 UTF-8 BOM 이 필수**다
(BOM 이 없으면 CP949 로 오독해 파싱부터 실패한다).

| 파일 | 하는 일 |
|---|---|
| `probe.ps1` | 서버 찾기 요청(12바이트)을 쏘고 응답을 16진수로 찍는다 |
| `listen.ps1` | UDP 18590 을 듣고 들어오는 패킷을 찍는다 (클라가 뿌리는 탐색을 잡을 때) |
| `nav.ps1` | 게임 창을 잡고 커서를 목표로 옮겨 클릭한 뒤 화면을 찍는다 |
| `capwin.ps1` | 창을 지목해 화면만 찍는다 (가려져 있어도 됨) |
| `mouseaccel.ps1` | 윈도우 마우스 가속을 끄고/되돌린다 (조준 계수의 전제) |
| `cycle.ps1` | **무인 한 바퀴** — 게임 기동 → 메뉴 4클릭 → 서버 개방 → 프로브 왕복 → 종료 |
| `loop.ps1` | 루프 운전 — 시도 횟수를 세어 **3회 실패면 정지**, 진행 기록에 한 줄씩 붙인다 |

## 화면을 몰 때 지켜야 하는 순서

이 게임은 마우스를 **OS 커서 위치가 아니라 이동량으로** 읽고, 창이 **진짜 활성일 때만** 받는다.
그래서 순서가 정해져 있다 (`nav.ps1` 이 이대로 한다).

1. ALT 를 살짝 눌러 "마지막 입력 주체"가 된 뒤 창을 앞으로 가져온다
   (다른 앱이 최상위면 `AppActivate` 만으로는 막힌다)
2. **창 안 빈 곳을 실제로 한 번 클릭한다** ← 빼면 이후 입력이 전부 무시된다
3. 이동량 `-3000,-3000` 을 여러 번 보내 커서를 좌상단에 붙인다 (기준점)
4. 목표까지 이동량으로 간다 — **화면좌표 = 보낸 값 x 3.06**

### 3.06 의 전제

**마우스 가속이 꺼져 있어야 한다.** 켜져 있으면 실제 배율이 ~2.18 로 어긋나 엉뚱한 버튼을 누른다.
`cycle.ps1` 은 조작 구간에만 끄고 **끝나면 반드시 되돌린다**.
창 크기(1280x960)와 이 PC 의 마우스 설정에서 잰 값이므로, 환경이 바뀌면 다시 재야 한다.

### 사람이 지켜야 할 것

- 조작 중에는 **PC 를 같이 쓰면 안 된다** (마우스·포커스를 공유한다)
- **화면 잠금이 걸리면 안 된다** — 잠기면 게임이 초기화 도중 멈춘다 (실측)

## 쓰는 법

```powershell
# 무인 한 바퀴 (도구가 있는 폴더를 -Sp 로 준다)
.\tools\cycle.ps1 -Sp (Resolve-Path .\tools)

# 서버가 떠 있을 때 응답 받아보기
.\tools\probe.ps1 -Targets @('127.0.0.1')

# 루프 기록
.\tools\loop.ps1 -Unit U0.1 -Attempt
.\tools\loop.ps1 -Unit U0.1 -Result OK -Detail "리포 정리"
.\tools\loop.ps1 -Status
```
