# Nox_MatchServer — 상용 클라이언트를 받아내는 서버

2000년 웨스트우드가 만든 쿼터뷰 액션 RPG **녹스(Nox)**의 서버를 직접 구현한다.
게임을 만드는 게 아니라, **남이 정한 프로토콜에 맞춰보는 것**이 공부의 알맹이다.

지금까지 만든 서버는 프로토콜도 구조도 판정 기준도 전부 내가 정했다.
여기서는 정답이 이미 정해져 있고 내가 거기에 맞춰야 한다.
1바이트만 어긋나도 클라이언트는 이유를 안 알려주고 연결을 끊는다.

## 왜 녹스인가

| 조건 | 상태 |
|---|---|
| 클라이언트를 정당하게 구할 수 있나 | **GOG에서 정식 판매.** DRM 없음 |
| 서버 주소를 바꿀 수 있나 | 멀티플레이 접속 시 지정 |
| 게임 로직이 서버에 있나 | **서버 권위 구조. 30Hz 고정 틱** |
| 프로토콜 자료가 있나 | `noxnet`(MIT)에 오프코드 242개 |
| 권리자가 어떻게 나왔나 | **2005년 EA가 공식 멀티를 커뮤니티 서버로 넘김** |

출처가 불분명한 클라이언트를 받아야 하는 대상은 전부 뺐다.
받는 것 자체가 복제물 취득이고, 무엇보다 그게 진짜 위험한 쪽이기 때문이다.

## 만드는 순서

동작하는 것부터 확보하고, 뜯어보고, 내 구조로 다시 짠다.

| | 하는 일 |
|---|---|
| 1. 포팅 | 클라가 붙고 캐릭터가 움직이는 데까지 |
| 2. 해부 | 왜 이렇게 짰는지 **명세 문서로 남김** (`Docs/PROTOCOL.md`) |
| 3. 재작성 | 내 구조(수신 루프·세션·틱·신뢰성 계층)로 다시 짬 |

2단계 문서가 1과 3 사이의 방화벽이다.
3단계에서 포팅 코드를 옆에 켜두면 같은 구조가 나온다. 문서만 보고 쓰면 결과물이 내 것이 된다.

**지금 이 리포의 코드는 1단계(포팅)다.** 설계·조사 문서(`Docs/`)는 리포에 올리지 않는다.

## 구조

    server/include/nox/   헤더 — 오프코드 표, 직렬화, 메시지 정의
    server/src/           구현
    client/               게임 설치본 (커밋 안 함)
    Docs/                 설계·조사 기록 (리포에 안 올림)
    tools/                캡처 분석, 빌드 스크립트

## 규칙

- **게임 설치본과 데이터 파일을 커밋하지 않는다.** 저작권 물건이다
- **패킷 캡처 파일(접속 한 판 통째)을 커밋하지 않는다.** 역분석 산물을 제3자에게 주는 것이 되므로.
  시험 기준값과, 뜻 모르는 자리를 정품 그대로 되돌려 보내는 값(`Recording.h`·`SnapshotTail.cpp` 등)만 메시지 단위로 코드에 옮겨 둔다
- **`opennox/opennox`(GPL-3.0)를 정답지로 읽는다.** Go 코드로 뜻을 알고 C++로 다시 짜고,
  디컴파일 C(`src/legacy/*.c`)로 대조한다(2026-09-12부터 — 처음엔 안 연다고 정했다가 뒤집었다)
- **opennox 소스를 고친 패치는 리포에 넣지 않는다.** GPL 원문이 통째로 들어 있어서다 — 로컬 기록(`tools/opennox-local/`)은 무시 목록에 있다
- 무엇을 어디서 가져왔는지는 `THIRD_PARTY.md`에 적는다

## 알아낸 것

| | |
|---|---|
| 전송 | **UDP**, 포트 18590 |
| 신뢰성 | 직접 구현. 헤더 1바이트 — 상위 비트가 reliable, 하위 7비트가 스트림 ID |
| 암호화 | **1바이트 XOR.** `SERVER_ACCEPT`에 키가 실려 오고, 그 전까지는 평문 |
| 오프코드 | 1바이트, 242개 (이름 미상 17개) |
| 틱 | 30Hz 고정 |

자세한 것은 `Docs/PROTOCOL.md`에 적는다.
★ **실제 트래픽으로 검증했다** (2026-09-10 정정 — 이 줄은 09-01 기준이었다).
판정은 정품과의 와이어 대조와 정품 클라 화면 확인으로 한다(서버 안 변수로 「돌았다」고 본 옛 기록은 근거로 안 씀 — `tools/README.md`).

## 법적 고지

- 이 리포는 EA(Electronic Arts)와 관계없는 개인 학습 프로젝트다. 「Nox」는 EA의 상표이고, 게임 녹스의 저작권은 © 2000 Westwood Studios에 있다
- 서버 코드는 [opennox](https://github.com/opennox/opennox)(GPL-3.0)를 참고해 짰다. 일부는 opennox에 든 디컴파일 C(`src/legacy/*.c`)와 대조하며 거의 그대로 옮겼다 — 출처는 `THIRD_PARTY.md`
- 그래서 이 리포의 코드도 **GPL-3.0**(`LICENSE`)으로 낸다
- 게임 자산(그림·소리·맵·글)과 데이터 파일 복호 키는 들어 있지 않다. 돌리려면 정품 녹스(GOG 판매본)가 있어야 한다
- 불법 복제를 돕지 않는다
